# Financial Modelling & Scenario Analysis

## Project Objective

This project demonstrates my ability to build and analyse a simple financial model using Microsoft Excel.

The model forecasts a company's financial performance over five years and allows the user to compare Base, Upside and Downside scenarios.

## What the Model Does

The model includes:

- Revenue forecasting
- Cost of sales
- Gross profit
- Operating expenses
- EBITDA
- Depreciation
- EBIT
- Tax
- Net income
- Capital expenditure
- Working capital
- Free cash flow
- Base, Upside and Downside scenarios

- Financial forecasting
- Profitability analysis

- Analytical problem solving
